НАУЧНЫЙ КВЕСТ — первая PWA-версия

Содержимое:
- index.html — приложение
- styles.css — интерфейс в стиле «Неоновая лаборатория»
- app.js — карта, карточки, истории, локальный профиль, достижения, демо-комнаты
- manifest.webmanifest + sw.js — установка PWA и базовый офлайн-кэш
- assets/ — иконка и вырезанные изображения персонажа из исходного листа

ЗАПУСК ДЛЯ ПРОВЕРКИ:
1. Распакуйте архив.
2. Откройте папку в редакторе/терминале.
3. Запустите локальный сервер из этой папки: python -m http.server 8080
4. Откройте http://localhost:8080

УСТАНОВКА НА ANDROID:
1. Разместите папку на HTTPS-хостинге (например, GitHub Pages/Netlify/Vercel).
2. Откройте HTTPS-адрес в Chrome на Android.
3. Меню браузера → «Установить приложение» / «Добавить на главный экран».

ОГРАНИЧЕНИЯ ПРОТОТИПА:
- Профиль и прогресс сохраняются локально в браузере.
- Командная комната демонстрационная и работает только на текущем устройстве; для игры с разных телефонов нужен сервер и realtime-синхронизация.
- Карта использует интернет, MapLibre GL JS и векторный стиль OpenFreeMap Dark (данные OpenStreetMap). Атрибуция отображается на карте; для работы карты требуется интернет.
- Координаты точек отмечены как предварительные там, где точное положение входа не было подтверждено. Проверить фактическое назначение, доступность и разрешения на посещение до публичного запуска.
- «Отметить посещение» сейчас демонстрационная кнопка; в релизе её следует заменить проверкой QR/геопозиции/модератором.

Версия 0.3:
- Добавлен каталог дополнительных научных/образовательных/технических точек Великого Новгорода.
- Можно вручную выбирать места для собственного маршрута.
- Порядок остановок подбирается по пешеходной матрице Valhalla.
- Каждый участок строится с costing=pedestrian и отображается по геометрии пешеходной сети.
- Маршрут не заменяется прямыми линиями при ошибке сервиса.
Важно: тротуары и проходы учитываются только если они нанесены в OpenStreetMap. Часть новых объектов — действующие кампусы/предприятия; доступ внутрь требует предварительного согласования. Координаты новых точек предварительные и требуют проверки на месте.

Версия 0.4 — исправления:
- Политехнический музей переименован в каталоге в «Политехнический музей Великого Новгорода», адрес Большая Московская, 8/7.
- Каталог и список точек отображаются независимо от успешной загрузки картографического стиля.
- Счётчик объектов рассчитывается из реального списка.
- Исправлена обработка выбора остановок и ошибок построения.
- Для маршрута используется Valhalla pedestrian; при недоступности сервиса показывается понятная ошибка, прямая линия не подставляется.
- При разрешённой геолокации старт — от пользователя; без неё — от первой выбранной точки (для одной точки требуется геолокация или вторая остановка).


ВЕРСИЯ 0.6 — подготовка PWA для Android:
- В названиях историй не показывается длительность: «Короткая история» и «Полная история».
- Истории расширены дополнительными пояснениями по направлениям.
- Добавлены управление озвучкой: слушать, пауза, продолжить и стоп.
- Исправлена обработка геометрии Valhalla: стандартный JSON-ответ содержит закодированную polyline6, которая теперь декодируется в координаты карты. Параметр shape_format=geojson не применялся к обычному JSON-формату, поэтому прежний код часто не находил координаты.
- Без геолокации маршрут между двумя и более выбранными точками начинается от первой выбранной остановки.

ПУБЛИКАЦИЯ ЧЕРЕЗ GITHUB PAGES:
1. Распакуй архив на компьютере.
2. На GitHub создай публичный репозиторий nauchny-kvest.
3. Открой папку nauchny-kvest внутри архива и загрузи именно её содержимое в корень репозитория (index.html должен лежать в корне).
4. В репозитории открой Settings → Pages.
5. В разделе Build and deployment выбери Deploy from a branch, Branch: main, Folder: /(root), нажми Save.
6. Дождись публикации и открой адрес вида https://ТВОЙ-ЛОГИН.github.io/nauchny-kvest/ на Android в Chrome.
7. В Chrome нажми ⋮ → «Установить приложение» (или «Добавить на главный экран»).

ВАЖНО:
- Для публикации через GitHub Pages нужен HTTPS, он предоставляется автоматически.
- После обновления файлов service worker может обновить кэш не мгновенно. Если приложение показывает старую версию, закрой его полностью, открой сайт в Chrome и обнови страницу.
- Профиль и достижения хранятся в локальном хранилище браузера. Не очищай данные сайта и не удаляй приложение, чтобы не потерять локальный прогресс.
- Перед использованием маршрута проверь его на местности: качество зависит от данных OpenStreetMap и доступности пешеходных проходов.
